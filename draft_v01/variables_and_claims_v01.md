配套[最小公设短稿](minimal_framework_v01.md)。本表将定义、模型内推论、外部证据和未完成任务分开；原稿转换文件保持原样。

## 变量表

| 符号 | 定义与单位 | 在v0.1中的地位 |
| --- | --- | --- |
| $m$ | 前作数论／谱构造的迭代索引，无量纲 | 与宇宙时间无已证实关系；$m=t/t_*$ 为新增平滑桥接。零点序号、零点高度也不自动等于$m$。 |
| $t,t_0,t_{\min},t_{\max}$ | 背景固有时间、今天、使用区间，统一使用秒或年 | 年采用365.25日；一切导数与参考尺度用相同单位。 |
| $t_*$ | 对数的参考尺度，时间单位 | 不是数值步长；须固定基准或明确带先验的共同估计。 |
| $n,\Delta t,t_{\mathrm i}$ | 数值步号、时间步长、起算时刻 | $n=0$ 完全允许，只需$t_{\mathrm i}>t_*$；不计算$\ln n$。 |
| $T,\tau,h$ | 固定时间单位、$\tau=t/T$、$h=\Delta t/T$ | $\tau,h$ 无量纲，改变$h$用来检查数值收敛。 |
| $L,L_0$ | $\ln(t/t_*)$、$\ln(t_0/t_*)$ | 要求$L>0$；不延拓到对数奇点。 |
| $s$ | 时间包络指数，主模型2，对照1与3 | 对应既有constant/CMB项目中的指数$p$，不表示动量。 |
| $f_s$ | $L^{-s}$，无量纲 | 被假定的慢变时间包络。 |
| $g,g_0,g_\infty,b$ | 结构参数、今天的值、渐近值、包络幅度，均无量纲 | $g_0=g(t_0)$；不把$g_\infty$指定为已知映射临界点。 |
| $q,P$ | 有限维实正则坐标和动量，均已无量纲化 | 经典有效状态，不是微观量子态；初值是模型输入。 |
| $\mathcal H$ | 无量纲有效哈密顿函数 | 未给出把它转换成真实能量的作用量尺度；它不是宇宙总能量。 |
| $K,K_n,\lambda_j$ | 势的对称矩阵、其时间取值、冻结矩阵特征值 | 与钟敏感度或零点谱数值不同；用来检查辛性、稳定性和相位。 |
| $\Omega_{a0}$ | 第$a$个有效探针今天的无量纲角频率 | $\Omega_{a0}=2\pi T\nu_a(t_0)$；相对标定量输入，不由数论推导。 |
| $\mathsf L=D-W$ | 固定有限图的正半定拉普拉斯矩阵 | $W=W^T\ge0$ 是局部权重，$D_{ii}=\sum_jW_{ij}$；普通邻接矩阵不代替$\mathsf L$。 |
| $v_{\rm lat}$ | 局部图耦合的无量纲系数 | 主钟接口置零；不是已测光速，图也未标定为宇宙空间。 |
| $\zeta,\Gamma$ | 电磁响应系数、乘积$\Gamma=\zeta b$，无量纲 | 观测仅约束乘积；不等于前作的谱拟合系数、12.73或Hubble幅度。 |
| $\alpha_0,\delta_\alpha,A$ | 今天的α、$(\alpha-\alpha_0)/\alpha_0$、$1+\delta_\alpha$ | α按同一低能定义比较；$A>0$。宇宙时间变化不同于随探测能量的重整化跑动。 |
| $\kappa_a,\Delta\kappa_{ab}$ | 跃迁对α的局部对数敏感度及差值 | 固定其他相关参数、相同频率约定；必须使用外部原子计算或测量，不能自由拟合来迎合信号。 |
| $\nu_a,R_{ab}$ | 周期频率、$\nu_a/\nu_b$ | 频率单位为时间$^{-1}$，比值无量纲；共同参考频率因子消去。 |
| $D,D_0$ | $d\ln\alpha/dt$、今天漂移，时间$^{-1}$ | 零兼容约束也直接进入有符号联合似然。 |
| $\mathcal T_s$ | 将当前漂移传递到过去相对变化的系数，时间单位 | 是模型函数，既不是宇宙年龄，也通常不等于回望时间。 |
| $z,t(z),H(t),H_0$ | 红移、背景年龄关系、膨胀率、今天的膨胀率 | 本版外部背景输入；不把不同方法估计的$H_0$分配成不同年代的实际$H(t)$。 |
| $\sigma_{\rm extra}$ | Clock方向的额外估计标准差 | 与均值漂移$\delta_\alpha$是不同对象，本版未指定它的动力学。 |

## 固定选择、未知参数与不能同时声称的内容

第一轮可辨识性计算拟固定$s$、一个$t_*$和一个背景，估计$D_0$及预先指定的校准干扰量。主模型$s=2$与对照$s=1,3$各有一个时间信号幅度；常数零假设少一个。自由估计$s$是另一模型，需要额外自由度。$g_\infty,b,\zeta$不能凭α拟合拆成三个测得参数。

为了与现有constant项目重现对照，可将$t_*$固定为$5.391247\times10^{-44}\,\mathrm s$这一常规普朗克时间数值。它在本模型中只是固定基准，既不随未知常数重新计算，也不解释为宇宙更新周期。改变该尺度会改变归一化和曲率，后续应对相同数据做共同的尺度剖面或敏感性检查。[现有约定](../../riemann_constant/paper/theory_section.tex)

采用$t(z)$时，以指定背景的宇宙时间为条件输入。在实验室使用的是经标准修正的本地频率比；本版假设其长期漂移可代表同一均匀背景。环境屏蔽、空间变化、引力势耦合或其他常数变化若存在，就需要另一个观测模型，不能事后加入而仍声称检验了原来的一幅度预测。

## 旧符号如何处理

| 原稿用法 | v0.1处理 |
| --- | --- |
| $u_c\simeq1.5437$、$u_c\simeq1.401$、logistic $r\simeq3.5699$混用 | 分别记录临界事件与坐标；前者为带合并，后两者为同一倍周期积聚事件的不同参数化。物理驱动用$g_\infty$，不偷换为这些点。 |
| $u_n=u_c-k/\ln^2n$被描述为持续远离临界点 | 对$k>0,n>1$，$u_n$递增趋近$u_c$。本版$b$保留正负，变化方向由导数确定。 |
| 同一个参数交替采用$1/\ln$和$1/\ln^2$ | 驱动固定平方律；只有明确的响应或积分关系才能产生另一指数，例如某系数的平方根，不把相同量任意换式。 |
| 非自治二次映射直接被称为辛宇宙引擎 | 一维二次映射仅供动机；式(2)是另行定义的正则有效系统，辛性单独证明。 |
| 共享逻辑地址、同步更新被等同于纠缠和超光速 | 本版不给出这些识别；固定时间背景不意味着可瞬时传输信息。 |

临界值的来源、固定参数坐标变换及非自治情形的限制见[来源审计](../reports/sources_v01_audit.md)。
