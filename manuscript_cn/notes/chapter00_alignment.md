# 第0章：与原文的对应及新内容来源

2026-09-23。新稿为[第0章介绍](../chapters/00_introduction.md)，对应原[Chapter 0: Introduction](../../chapters/01_chapter_00_introduction.md)。保留I—VIII的总体顺序；II、III、IV、V的子节功能也分别对应原章。正文采用连续论述，旧稿到新稿的修改理由放在本说明中。

## 八部分如何融入新内容

| 原部分 | 中文稿的处理 | 融入的新材料 |
| --- | --- | --- |
| I. Synchronization Crisis | 以微观—宏观、内部演化和可观测参数为研究问题；观测张力是动机。 | 区分$H(t)$与方法推断的当前$H_0$；可变耦合需要动力学和物质接口。 |
| II. Riemann Kernel | 保留谱统计、符号编码、算术输入和非自治响应四层。 | 纳入两篇2026年发表前作；明确映射索引与物理时间不同、一维映射不自动成为辛体系；写入无量纲对数的候选响应。 |
| III. Cosmic Lockstep | 保留同步规则、状态系统及逻辑／空间描述。 | 区分架构设想与连续模型时间下的计算基准；内部时钟参与反馈，均匀模式的局域性问题明确保留。 |
| IV. Mathematical Framework | 按演化结构、参数行为和连续描述展开。 | 共同哈密顿量、相反能流、纯包络分支的条件晚时保持、长波方程与格距修正；详证继续纳入第4章。 |
| V. Observational Evidence | 写成数值依据与观测接口，保留常数、膨胀和实验室约束。 | 八块1593例算术对照；四个物理项目的不同作用；同一$\Gamma$连接当前漂移和过去变化的条件关系及形状识别问题。 |
| VI. Predictions & Interpretations | 保留不确定性、纠缠、真空、引力和波粒行为五个问题。 | 分别列出需要的测量规则、概率分布、物理能量、局域结构和检验，避免仅凭工程类比声称已经解释。 |
| VII. Riemann Engine | 保留ECS和可执行引擎目标。 | 已有分层求解、独立参考、误差检查、替代输入与合成恢复；完整ECS调度和跨硬件逐位一致仍属设计目标。 |
| VIII. From Geometry to Computation | 总结当前可陈述的成果和原第1—9章安排。 | 算术输入已接入，特殊响应未检出；从算术结构导出真实物理相互作用仍是核心任务。 |

原章末的“RSM对比ΛCDM”表把不同层次的理论和工程类比放在同一列。它的主题已分别纳入I、V、VI部分；待第9章再基于已经写出的候选、观测量和结果形成有明确范围的对照表。旧表中的超光速通信、真空取能和“宇宙破解”未被保留为成果；相应的因果性、能量和可预测性问题在新稿中继续处理。
