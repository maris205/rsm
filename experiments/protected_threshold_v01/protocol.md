# 对称性保护的带电阈值：预定协议 v0.1

2026-09-25，生产计算前冻结。问题：一个明确的全局N=1超对称启发物质完成，能否抵消重带电场的m⁴势能反馈而保留电磁响应？驱动势自身的F项破缺和额外soft质量如何改变答案？这是条件理论实验，无新观测、无新零点数据，也不宣称SUSY或质量律由黎曼结构推出。

## 模型与有限范围

1. 中性手征场Z和电荷±1的Q±，canonical Kähler势；W=W0(Z)+M(Z)Q+Q−。实轨迹Z=Fχχ/√2。W0选择使|W0,Z|²=Utree=Fχ²Href²Wi exp[−2(χ−χi)]；M的局部全纯分支满足s=|M|²=mi²g，g=[1+(χi/χ)²]/2，χ>0。无真实Q占据，电磁D=0。重场谱为Dirac费米子s、两个复标量s+d±h，h=√Utree|M_Z|，d=msoft²≥0。W0非零时并非未破缺超对称。
2. 采用保持玻费计数一致的一圈局部势方案，f(s)=s²[ln(s/μ²)−3/2]，U1=[f(s+d+h)+f(s+d−h)−2f(s)]/(32π²)。只扣U1(χi)常数，不扣斜率/曲率、不调Λ。d=h=0仅作代数对照，不把该极限和非零树势一起宣称完整未破缺宇宙。
3. 固定UV边界的阈值权重为(1/3,1/3,4/3)，退化极限总b=2；势能的统计符号与规范beta贡献不同。每例今天用同一个α0约定归一读数，不声称不同case的UV数值边界完全一致。完整split质量对数式与小变化χ⁻²响应比较。
4. 本轮仅取常χ动能完成。沿用前实验charged_threshold_v01冻结的χi、qi、taui、Wi、epsilon=10⁻⁴、Href、Fχ、流体与Λ，区间z=4.2→0，不重跑早期背景。主粒子质量mi=100 GeV是预设层级例，满足光学动量较小的必要条件，但未核查其粒子实验/热史可行性。
5. 在匹配到同一势方案的有限Kähler约定中使用ΔK_ZbarZ=−|M_Z|² ln(s/μ²)/(16π²)；其给势的F²修正已经包含在CW中，不能再加Utree/(1+ΔK)的第二份同阶修正。split引起的更高阶动能项不精确计算，报告耦合与d/s、h/s的误差尺度。保留已知Kaehler项；误差预算未通过时不得称此截断受控。
6. 背景并非完整SUGRA或现实可见区超对称完成；无热占据、可见区soft传递及物质标量源。正交ImZ方向树级平坦，须报告一圈横向曲率和实轨迹的不变性，不将一维积分称稳定单场模型。

## 固定案例与计算量

- 主μ=mi；定义ηsoft=d mi²/(8π² Fχ²Href²)。预定ηsoft=0、1、100、10⁴、10⁶，5条轨迹；每条都包含时钟自身h，ηsoft=0不是丢掉F项。先执行这些点，不挑选有利结果。
- 稳定计算采用小分裂展开：共同d部分保留至d³（可按需要包含更高阶）；对称h部分至少h²及h⁴项，含完整χ依赖与导数。避免用double直接相减约10⁴⁴ eV⁴的大数获得微小残余。主误差需在本协议固定节点与独立高精度supertrace比对。
- 在旧canonical χ树级轨迹上，mi=1 eV、1 MeV、100 GeV各计算F项预算；共同soft预算取μ/mi=1/2、1、2，用固定有限参数不随μ运行的诊断，明确它比较有限匹配选择，不是物理RG不变性检验。在每个选择下给max|U1,χ|/|Utree,χ|≤0.1的d预算上限，这只是慢时钟诊断，不是观测允许区间。
- 另固定msoft=1 GeV列出重粒子100 GeV预算，显示常规较大soft分裂不会自动安全；不强行积分其极端背景。
- 不改变指数、预定初态、树势或常数减法以追求单调轨迹；任何反转、有效域终止或核验失败都保留。
