# 独立高精度势能与阈值核验

## 范围与方法

本核验读取旧实验 `charged_threshold_v01/results/inputs.json` 和保存的 `chi_probe` 树级轨迹，不积分新的宇宙背景。材料为本地公开理论模型参数，无观测拟合。节点、质量、soft 分裂和重整化尺度的组合在本实验 `protocol.md` 中预定；总计 270 个点。

独立程序 `code/independent_precision.py` 直接计算三个行列式项的差，没有导入主程序的小分裂级数。每点分别使用 mpmath 320 位和 400 位十进制算术，并把直接势的 `mp.diff` 导数与直接解析导数比较。高精度算术只用来处理极大数相消，不表示输入参数或物理预测具有相应精度。

计算严格使用

\[
g(\chi)=\frac12\left[1+(\chi_i/\chi)^2\right],\qquad g(\chi_i)=1,
\]

避免已四舍五入的独立 \(\xi\) 输入造成初始微小偏移。固定每例 \(\mu/m_i\)，只扣除初始势常数，不扣斜率或曲率。

## 解析交叉检查

设 \(L=\ln(s/\mu^2)\)，分子为 \(N=f(s+d+h)+f(s+d-h)-2f(s)\)。在正质量、小分裂条件下，

\[
N=2[f(s+d)-f(s)]+2h^2\ln\frac{s+d}{\mu^2}
-\frac{h^4}{6(s+d)^2}-\frac{h^6}{30(s+d)^4}+\cdots,
\]

其中共同 soft 部分为

\[
2[f(s+d)-f(s)]
=4sd(L-1)+2d^2L+\frac{2d^3}{3s}-\frac{d^4}{6s^2}+\cdots.
\]

上述分子最后均除以 \(32\pi^2\)。当 \(d=0\) 时，主导 F 分裂势为 \(h^2L/(16\pi^2)\)，其导数为

\[
U_{1,\chi}=\frac{2hh' L+h^2s'/s}{16\pi^2}+O(h^4).
\]

因此，\(\mu=m_i\)、初始 \(L=0\) 时，势的 \(h^2\) 项消失，但力的 \(h^2s'/s\) 项仍在。初始真正的非零势首项为

\[
U_1(\chi_i)=-\frac{h_i^4}{192\pi^2s_i^2}+O(h_i^6/s_i^4).
\]

未破缺代数对照 \(d=h=0\) 的势和力准确抵消，而带电阈值不抵消。这只是代数对照，不能和非零驱动 F 势同时当作一个完整未破缺宇宙模型。

## 结果

320 位与 400 位直接计算的最大相对差为 **3.88×10⁻¹³⁹**；直接势数值微分与解析导数的最大相对差为 **1.23×10⁻³⁰⁹**。退化抵消、阈值不抵消、初始 \(h^4\) 残余和初始非零 F 力的检查全部通过。精确值、输入与代码哈希、全部 270 个点保存在 `results/independent_precision.json`；命令输出保存在 `results/independent_precision_run.log`。

以 \(m_i=100\,\mathrm{GeV}\)、\(\eta_{\rm soft}=0\)、\(\mu=m_i\) 为例：

| 量 | 独立直接计算 |
|---|---:|
| 初始 \(h/s\) | \(5.23707\times10^{-46}\) |
| 初始未扣常数 \(U_1\) | \(-3.96965\times10^{-141}\,\mathrm{eV}^4\) |
| 初始 \(U_{1,\chi}\) | \(-1.26184\times10^{-51}\,\mathrm{eV}^4\) |
| 树级轨迹末端 \(|U_{1,\chi}/U_{\rm tree,\chi}|\) | \(3.16837\times10^{-38}\) |

## 与主程序的交叉比较

将上述直接高精度结果与主程序 `run_protected.py` 的公共函数 `evaluate_loop` 比较；独立程序没有复用该函数的展开式。全部 270 个点通过预定 \(10^{-8}\) 相对容差：

| 量 | 最大相对差 |
|---|---:|
| 未扣常数的 \(U_1\) | \(7.73\times10^{-13}\) |
| \(U_{1,\chi}\) | \(7.79\times10^{-13}\) |
| \(U_1(\chi)-U_1(\chi_i)\) | \(1.56\times10^{-12}\) |
| \(h^2\) | \(2.21\times10^{-14}\) |

比较使用每个实际非零物理量作分母；共享初始点的扣常数势要求精确为零。初始 \(h^4\) 微小项没有用大树势作为误差分母而掩盖。最大误差主要来自用双精度表示 \(\chi_i+u\) 等输入，而非所保留项的明显截断误差。

此外读取主程序归档的五条新轨迹，在每条的六个预定索引上用直接高精度完整 split 质量对数式重算阈值，共 30 点。\(\Delta\alpha/\alpha\) 最大相对差为 **3.35×10⁻¹³**，也通过容差。逐点比较及主代码、轨迹哈希保存在 `results/independent_comparison.json`。

270 个点是保存的树级轨迹上的算术和函数值核验；额外 30 个点是在主程序轨迹上的阈值复算。二者都不是带反馈轨迹的独立 ODE 解。背景数值误差、有效场论截断和物理完成的充分性仍需分别判断。高精度一致性不能验证超对称假设、质量函数、匹配选择或宇宙学解释是否真实。

复现命令（限时 180 秒）：

```bash
timeout 180s python experiments/protected_threshold_v01/code/independent_precision.py
```

内部 AI 协助的程序和解析审计不等同于外部同行评审。
