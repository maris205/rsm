# α 注入恢复 v0.1：独立结果复核

2026-09-22。审查主实现 [`run_recovery.py`](../code/run_recovery.py)、[协议](../protocol.md)和全部汇总表。结论：**未发现改变本轮主要结论的统计计算错误；结果支持“当前设计可约束漂移幅度，但不能区分三个邻近指数”这一条件判断。** 它没有检验出真实宇宙的非零演化。

## 1. 独立核验方法与结果

新增[独立核验脚本](../code/independent_statistical_check.py)及[207项核验记录](independent_statistical_checks.json)，全部通过。此脚本不导入主实现：用整数指数的闭式有理函数计算传递关系，以完整协方差的GLS正规方程估计幅度和偏移，再以新的随机数逐行生成完整观测噪声，检查主实现压缩三分数模拟的统计行为。独立核验读设计表，不读实测α或钟均值。

整数指数的独立传递式例如

$$
\mathcal T_2=t_0\frac{L_0\ell(2L_0+\ell)}{2(L_0+\ell)^2},
\qquad\ell=\ln[t(z)/t_0],
$$

与主代码的 `expm1/log1p` 形式解析等价，但数值路径不同。七种设计的幅度误差、分数相关矩阵、133个情形的固定平方律解析功效和42组形状残差均与存档相符。另对每种设计用16,000次新生成的完整观测噪声交叉检查零假设；此核验只验证实现，不新增观测证据。

| 核验项 | 结果与意义 |
| --- | --- |
| King无偏移的平方律 $\sigma_d$ | 509.12431727；独立GLS一致。 |
| King双仪器偏移的平方律 $\sigma_d$ | 1842.62688836；允许偏移使历史幅度信息减少。 |
| 主联合设计的平方律 $\sigma_d$ | 2.49999769901；几乎由钟点决定。 |
| 主联合设计的钟信息比例 | 0.9999981592，即99.9998159%；不能将联合幅度检测说成天文曲线识别。 |
| 主联合设计 $s=2\to1$，$d=2.5$ | 最优错误幅度与偏移之后的残差 $\lambda=1.36346594\times10^{-10}$。 |
| 主联合设计 $s=2\to3$，$d=2.5$ | $\lambda=1.38907797\times10^{-10}$；形状差异远小于误差。 |
| 当前钟误差的1、2、5倍平方律注入 | 主联合固定平方律检测功效约17.0%、51.6%、99.88%；幅度检出不意味着指数被辨认。 |
| 自由ESPRESSO单点偏移 | 历史信息被该偏移完全吸收，三个投影列相同，只剩钟幅度。 |

`Design`在相关噪声下先除各行标准差、再用相关矩阵Cholesky白化，等价于完整协方差GLS。偏移也接受相同白化。归一化残差列的QR分解给出的三分数协方差正确；没有裁剪近零特征值来人为拉开模型。ESPRESSO两行时QR因子为2×3，也能生成正确的秩不超过2的三个分数。

## 2. 误报率、覆盖率与模拟误差

七个设计各使用独立的 `SeedSequence` 子流用于30,000次零校准、20,000次恢复评估和小批完整WLS核验，未发现校准和评估重复使用同一组噪声。各注入共用评估噪声，因此覆盖率随幅度保持相同属于线性高斯结构和共同随机数的预期行为；**133个情形不是133份独立证据。**

主设计存档的固定平方律零误报率为4.795%，95%区间覆盖率为95.205%；扫描三个指数后的误报率为4.63%。扫描阈值由有限零模拟估计，误报率误差同时含校准和评估两部分。近退化的本情形，在5%附近的合并标准误约为

$$
\sqrt{0.05\,0.95\left(\frac1{20000}+\frac1{30000}\right)}
=0.001990,
$$

即0.199个百分点。4.63%与5%的差异约为1.86个合并标准误，不构成校准失效。某些经验扫描阈值略低于理论单模型95%分位数，也是有限校准抽样可能出现的结果，不代表三个模型扫描有负惩罚。

原 `recovery.csv` 的 `detection_mc_se` 对应固定平方律检测，不能直接挪作扫描检测误差条。[独立核验JSON](independent_statistical_checks.json)另列每个设计的扫描评估条件标准误与上述合并标准误。常规覆盖率只针对预固定的正确指数，不是选模之后的区间覆盖率。

AIC选择与5%检测已分别记录：常数模型少一个幅度，非零候选胜过常数的AIC规则等价于最大 $\Delta\chi^2>2$，所以零注入时AIC选择非零的概率约15%—16%是规则本身的结果。主结果中中间指数获选很少，也符合近共线方向的几何，不能解释为平方律被这些模拟否定。所有当前注入的候选间AIC差达到2的比例均为零；仅看裸胜率会误导。

## 3. 尺度剖面和理想精度预算

另一路完整白化WLS核对了尺度剖面和四个误差预算求根。先做1001个尺度网格检查，再作局部优化，得到：

- $s=1$最优 $L_0\simeq93.71341156$，残差 $\lambda\simeq1.42359678\times10^{-16}$；
- $s=3$最优 $L_0\simeq186.77483360$，残差 $\lambda\simeq3.54264623\times10^{-17}$。

它们与存档一致。允许候选参考尺度变化进一步减弱指数辨识力。原因可从展开看出：

$$
\mathcal T_s=t_0\left[\ell-\frac{(s+1)\ell^2}{2L_0}
+\frac{(s+1)(s+2)\ell^3}{6L_0^2}+\cdots\right].
$$

改变指数后，把候选尺度约取为 $(s+1)L_{0,\mathrm{true}}/3$，就能匹配平方律的二阶项。此诊断并未拟合实际测量，也不附加常规1df显著性。

主误差预算固定参考尺度、保留当前293行红移布局和两个仪器偏移，仅同比缩小全部天文标准误，钟误差保持不变。$d=2.5$时，要使对最近相邻指数的残差达到1或9，分别需约 $5.15\times10^5$、$1.545\times10^6$倍的误差缩小；对应天文标准误中位数约 $3.46\times10^{-5}$、$1.15\times10^{-5}$ ppm。四个预算点独立求根相对差约 $10^{-9}$，与主求根精度一致。

这些是严苛理想假设下的条件算例，**不是未来十年仪器性能预测，也不是参考尺度自由时的预算**；它把历史附加散布也按同一比例缩小，没有预留不可消除的系统误差地板。非嵌套形状的残差9不能直接称为3σ发现。需要更合适的独立可观测关系或外部尺度信息，单靠当前布局下小幅提高精度不足以挑出平方指数。

## 4. 十一类统计风险在本任务中的适用性

| 风险 | 本模拟中的状态 | 已控制的部分和仍有的边界 |
| --- | --- | --- |
| 分组依赖 | 适用，部分控制 | 保留QSO标签并加入ρ=0.25敏感性；这不是测得的真实协方差，未证明现实各组独立。 |
| 聚合偏差 | 适用，部分控制 | 分列King、钟联合和ESPRESSO；不把钟主导的联合结果外推为历史曲线信息。原始光谱仍被压缩。 |
| 选择偏差 | 适用，模拟内控制 | 固定继承作者筛选、不按新残差剪裁；真实样本选择过程没有被重新建模。 |
| 碰撞变量偏差 | 本生成模型不引入；现实仍待查 | 合成响应不决定入样或阈值取舍；不能据此排除实际可观测性/信噪比筛选造成的碰撞偏差。 |
| 基准率忽视 | 适用，已约束解释 | 检出率、误报率、AIC胜率不称为假设为真的概率；本实验没有宇宙模型先验概率。 |
| 回归均值 | 模拟设计内控制 | 注入由预定义幅度决定，不挑异常实测值作为起点；无独立重复测量的因果叙述。 |
| 幸存者偏差 | 模拟输出内控制 | 零和非零、正负、所有指数及失败分辨的情形均保留；历史目录的不完备性仍条件化。 |
| 多重检验 | 适用，固定扫描已控制 | 三指数最大统计量用独立零模拟校准；尺度敏感性不择优宣称发现，未来扩大搜索需重新校准。 |
| 分析分叉 | 适用，已记录边界 | 协议先于本轮主MC，且说明不是盲分析/外部注册；尺度剖面作为诊断，不包装成预注册发现。 |
| 相关当因果 | 因果识别不适用；防止外推 | 真值在模拟里由程序规定，恢复它只证实条件统计能力，不能证明算术结构导致α演化。 |
| 反向因果 | 本模拟不研究 | 合成数据没有从响应反推生成机制的因果识别步骤；不能由成功恢复宣称现实因果方向已确定。 |

## 5. 可保留的结论

目前程序和统计设计在规定假设下自洽。幅度区间、检测功效、近退化形状、尺度退化和理想误差预算均得到独立路径复核。应保留的科学表述是：**已有红移覆盖与压缩误差预算可以支持一幅度约束实验，但现有精度下的联合信息几乎来自当代钟，无法独有地区分 $1/\ln^2$ 与相邻指数。** 本轮没有添加真实α变化的观测证据，也未验证黎曼结构到原子响应的微观桥接。
