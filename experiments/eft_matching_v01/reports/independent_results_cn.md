# 带电二阶部门的独立数值复核

日期：2026-09-25。对应 [实施说明](../protocol.md)。本报告复核指定局部系数部门的代数、谱函数和数值实现，**不构成完整超引力量子匹配、观测验证或外部同行评议**。

## 复核范围和独立性

独立脚本 [independent_check.py](../code/independent_check.py) 未读取或导入主实现。输入仅使用父实验 `sugra_shift_v01` 的参数文件、1025 个 `shift_axis` 的 χ 坐标和本轮实施说明。先独立推导并计算，再读取主实现的 CSV 输出作比较。相位使用精确的 `(cosθ,sinθ)=(1,0),(0,1),(-1,0)`，不以浮点 `cos(π/2)` 代替零。

此处把 c、β²、ν 作为给定的局部重整化系数，采用局部几何中心上的 X 和相同的参考力 2U。计算没有加入已知基线 B：直接谱函数核验的是额外 B 平方部门，基线与新增 B 的干涉由主报告另行估计。若系数本身来自一环，其插入带电一环的总阶数需另计。完整的混合图、动能归一化、辅助场 1PI 项、引力与 ghost 行列式、其他局部势函数均不在本检查中。

## 从谱函数直接得到响应核

取两带电复标量的质量平方为

\[
m_\pm^2=s-cX\pm\sqrt{\beta^2sX},\qquad m_F^2=s,
\]

并定义

\[
F(u)=u^2\left[\ln(u/\mu^2)-\frac32\right],\qquad
V_{\rm det}=\frac{F(m_+^2)+F(m_-^2)-2F(s)}{32\pi^2}.
\]

共同分裂的一阶项和 B 的平方项分别来自 `2d F′(s)` 与 `|B|² F″(s)`。令 p=sX、L=ln(s/μ²)，得到

\[
V_{\rm sel}=\frac{p}{8\pi^2}\left[\left(-c+\frac{\beta^2}{2}\right)L+c+\nu\right].
\]

对 A∈{χ,y} 求导，三个单位响应为

\[
\begin{aligned}
K_{c,A}&=\frac{-s_A X L+sX_A(1-L)}{8\pi^2},\\
K_{\beta^2,A}&=\frac{s_A X(L+1)+sX_A L}{16\pi^2},\\
K_{\nu,A}&=\frac{s_A X+sX_A}{8\pi^2}.
\end{aligned}
\]

这里 Kc 已先解析消去在 L=0 处相反的 `s_A X` 项；直接相减会丢失初始点上非常小的剩余分量。代码按精确初始质量归一化 `s=Mi²(1+ξ/χ²)/(1+ξ/χi²)`，验证 s(χi)=Mi²，Mi=100 GeV。

横向导数另由完整组合

\[
S/P=3m_Ge^{i\theta}+r(3+2iy)e^{-iy},\qquad
r=w_r/P,\qquad X=|S/P|^2/9
\]

数值微分恢复，得到 `X_y=−2mG r sinθ/3`。它含有的 1/3 不能由实轴 `|W|²` 的朴素延拓替代。最终归一化导数残差为 **6.98×10⁻⁸²**。

## 完成的数值检查

- 独立计算 4 个 mG 选点 × 3 个相位 × 1025 个坐标，共 **12,300 个响应点**；三个系数分别给出 χ、y 和二维范数预算。这里的旧红移标签只是父坐标的索引，不是新模型的宇宙解。
- 对四个独立选点索引 `0,173,701,1024`、四个匹配尺度 `μ/Mi=0.5,1,2,10`，以及正/负 c、β²、ν、混合系数和两个有限 ν 边界，共 **1,344 个谱函数点**。每一点用 **160 位和 220 位**直接计算对数谱函数及其导数，没有用小分裂展开替代直接谱函数。
- 在这些采样点，160→220 位的最大力差除以 2U 为 **5.53×10⁻¹⁰⁶**；直接谱函数与保留阶结果的最大力差除以 2U 为 **2.17×10⁻⁵⁴**。后者是本组谱函数的小分裂截断误差，不包含尚未计算的其他图或算符。
- 在所选系数取值下，最大 `|d|/s=9.13×10⁻⁵⁵`、最大 `|B|/s=1.62×10⁻²⁸`。不存在测试谱中的负质量平方。
- 独立推导与精度批次 **22/22** 检查通过；读入主输出后的比较批次 **261/261** 通过。检查数量描述软件验证覆盖，不是相互独立的物理证据。

直接谱函数比较统一用 2U 归一化误差；在某些匹配点，单个保留阶分量可接近零，不能用该分量作分母并把结果解释为整体失效。所有直接值、导数、分裂比和误差均保存在 [independent_direct_cw.csv](../results/independent_direct_cw.csv)。

## 预算、尺度闭合和退化

主有限边界 ν₀=0，mG=1 eV、θ=0 时，独立重算的逐系数 10% 条件为

| 单独变化的系数 | 全 1025 点的 10% 条件 |
|---|---:|
| \(|c|\) | 1.231998201276898×10⁻³² |
| \(|\beta|\) | 1.962686879516452×10⁻¹⁷ |
| \(|\nu|\) | 1.896421790837632×10⁻³⁴ |

它们是指定部门、边界条件及参考力下的**条件容忍度**，不是观测上限，亦不意味着三个系数可以同时各自耗尽 10% 预算。完整结果保存在 [independent_budgets.csv](../results/independent_budgets.csv)。

写 `A=−c+β²/2`，保持同一 ν₀ 且令

\[
\nu(\mu)=\nu_0+2A\ln(\mu/M_i),
\]

便抵消此保留阶的显式 log。独立任意系数组合的尺度闭合最大残差除以 2U 为 **2.00×10⁻⁸⁰**。改变有限边界为 ν₀=−c 或 ν₀=−β²/2 是改变局部系数选择；这些边界的预算也分别重算，不被误称为同一匹配模型的尺度误差。

全网格恒等式

\[
K_c+2K_{\beta^2}-K_\nu=0
\]

最大归一化残差为 **3.90×10⁻⁸¹**。把 `(Kχ,Ky)/(2U)` 按坐标堆叠后，各列作 L2 归一化；mG=1 eV、θ=0 的奇异值约为 `(1.72935,0.0966984,3.70×10⁻¹⁶)`。所选部门只有两个可辨识的势形组合，零方向不等于量子保护对称性，也不保证其他阶或其他算符沿同方向消失。

与主输出的比较范围包括 36 个逐系数预算、全部 3,075 个已存主响应点、全部 192 条 RG 对照，以及 24 个改变有限边界后的预算。最大差异为：

| 比较对象 | 最大归一化差异 |
|---|---:|
| 逐系数预算 | 1.564×10⁻¹⁴ |
| 响应核，按该列全网格向量范数归一化 | 1.213×10⁻¹⁴ |
| RG 输出 | 2.654×10⁻¹⁴ |
| 改变有限边界后的预算 | 1.400×10⁻¹⁴ |

比较统一阈值为 10⁻¹¹，没有为近零点逐个放宽阈值。更多数值细节见 [独立汇总](../results/independent_summary.json) 和 [主输出比较](../results/independent_comparison.json)。

## 保留的失败与修正

第一次批次为 **21/22**：在仅 80 位精度下，对被 mG² 背景主导的完整 `|S|²` 求横向导数，归一化残差为 1.52×10⁻⁴⁷，未达到事先设定的 10⁻⁷⁰ 阈值。把此独立数值微分提高到 160 位后通过，**阈值未改变**。初始结果和日志完整保存在 [independent_initial_diagnostic.json](../results/independent_initial_diagnostic.json) 与 [independent_initial_diagnostic.log](../logs/independent_initial_diagnostic.log)。

复核代码同时发现 Kc 初始点的直接相减形式可能掩盖微小的正交相位分量，改为上文给出的解析消去形式，并重算全批次；这项修正未改变主要预算。未发生物理结论相反的测试被删除或容差被放宽的情况。

归档时 Git 检查把 CSV 默认 CRLF 行尾报告为行末空白。仅将写入器改为 LF，重新运行推导及输出比较，并逐文件核对规范化后的内容字节保持相同；没有改动数值或比较容差。变更前哈希与核对结果分别在 `results/csv_format_diagnostic.json`、`results/csv_format_verification.json`。

## 复算和材料说明

从仓库根目录运行：

```bash
python experiments/eft_matching_v01/code/independent_check.py --derive --compare
```

`--derive` 只依赖本轮实施说明和父参数/坐标；`--compare` 另外需要主输出 CSV。最终代码、输入和实施说明的 SHA-256 保存在独立汇总，主输出的 SHA-256 保存在比较汇总。运行环境为 Python 3.12.3、mpmath 1.3.0、NumPy 2.4.4。报告没有引入新的观测数据或文献物理主张；公式是在本轮明确假设下从谱函数独立推导。

本报告由同一 AI 系统内的分工代理完成独立实现和内部复核；这种独立性针对代码路径和数值计算，不应称作独立研究团队或外部同行评议。结果支持所选有限部门计算的一致性；能否固定并保护 c、β、ν 以及其他未定函数，仍需明确的微观模型或对称结构。
