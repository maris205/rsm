# 球对称塌缩参考与连续补偿初态核验

日期：2026-09-24。此记录只覆盖球对称 ODE、连续初态和保存文件的完整性；PM 的离散力、颗粒采样及形状误差另行检验。这里的 \(\Delta=200\) 是**首次达到指定平均密度的事件**，不表示维里化、真实晕识别或星系形成。

## 设置与可复算入口

按[冻结协议](../protocol.md)复用此前保存的参考背景及 \(\epsilon=10^{-4}\) 时钟背景；协议 SHA256 为 `f3a0cc5abf21a4374439db756cbf8c4a3103bcabfa2bee6f9bd1921b28e608f2`。固定 \(a_i=0.02\)、\(q_L=2.5\,\mathrm{Mpc}/h\)、补偿半径 \(q_c=4\,\mathrm{Mpc}/h\)。核心连续拉格朗日质量为 \(5.7218898744\times10^{12}\,M_\odot/h=8.4894508523\times10^{12}\,M_\odot\)。

以 \(y=r/(a q_L)\)、\(N=\ln a\) 求解

\[
y_{NN}+(2+\mathrm d\ln E/\mathrm dN)y_N+
\frac12\Omega_m(a)(y^{-3}-1)y=0.
\]

参考初始幅度只按预设数值事件 \(a_{200}=0.5\) 求根一次，得到 \(\delta_i=0.07295182597218097\)。这不是对观测拟合。初始速度采用协议指定的有限起点约定，并非精确非线性纯增长支。两背景共用实际初始动量，故时钟背景 \(y_{N,i}\) 乘 \(E_{\rm ref}(a_i)/E_{\rm clock}(a_i)\)。本轮固定牛顿常数、粒子质量及原子速率，时钟仅通过背景膨胀史和年龄进入。

在仓库根目录运行：

```bash
python experiments/halo_cooling_v01/code/spherical_collapse.py
python experiments/halo_cooling_v01/code/verify_sphere_profile.py
```

第一条复算球塌缩及其独立参照，第二条只检查现存结果和连续初态，不重新积分 ODE、不运行 PM。[生产结果](../results/sphere_summary.json)及[补充核验结果](../results/sphere_profile_check.json)包含代码、版本、命令与哈希。首次补充核验前已在[独立脚本](../code/verify_sphere_profile.py)中固定实现诊断容限；它们不冒充冻结生产协议新增的预注册科学门限。复算会保存既有 JSON 的哈希命名副本，不删除失败记录。

## 连续窗口为何补偿且不发生初始壳层交叉

\(W(q)\) 表示**包围平均密度增量的窗口**，不是局部密度。过渡区令 \(s=(q-q_L)/(q_c-q_L)\)，独立核验采用与生产代码不同的因式形式：

\[
W=(1-s)^3(1+3s+6s^2),\qquad
W_q=-\frac{30s^2(1-s)^2}{q_c-q_L}\le0.
\]

它与核心常值 1、外部常值 0 在两端达到二阶连续。初始径向映射 \(x=qy(q)\)，其中 \(y=(1+\delta_iW)^{-1/3}\)，体积 Jacobian 为

\[
J=y^2(y+q y_q)
=\frac{1}{1+\delta_iW}
\left[1-\frac{\delta_i qW_q}{3(1+\delta_iW)}\right]
\ge\frac{1}{1+\delta_i}>0.
\]

因此连续初态映射单调、没有壳层交叉；这是解析不等式，不依靠有限网格的最低值来推断全域正性。质量守恒给出局部 \(\rho/\bar\rho=J^{-1}\)。稠密采样中局部密度比的范围约为 **0.9357824—1.0729518**；过渡区域确实包含欠密度，以抵消核心超额。它并非全空间处处正超额密度。

包围在 \(q_c\) 内的总质量超额满足

\[
\frac{\Delta M}{4\pi\rho_{m0}}
=\int_0^{q_c}(1-J)q^2\,\mathrm dq
=\left.\frac{q^3-(q y)^3}{3}\right|_0^{q_c}=0,
\]

这里 \(\rho_{m0}\) 是不随时间变化的平均共动质量密度，不能直接换成初始时刻的物理密度。因为 \(W(q_c)=0\)、\(y(q_c)=1\)。外围没有位移、没有额外包围质量，局部密度回到背景值。理想连续球的初始外部扰动力因此为零；这不消除离散 PM 的网格各向异性、颗粒噪声或后续数值误差。

补充核验 **59/59 通过，0 项失败**，与 ODE 的 42 项分别计数：

- 在 17 个半径、6 个方向上，用独立四阶笛卡尔有限差分求三维映射行列式；与径向解析 Jacobian 最大相对差为 \(1.43\times10^{-11}\)，实现容限 \(10^{-7}\)。
- 独立体积积分给出核心超额 **0.35412347296596636**、过渡区净亏缺 **−0.35412347296596436**，单位为 \(4\pi\rho_{m0}\) 乘所用坐标体积单位。总和约 **\(2.00\times10^{-15}\)**，相对整个补偿球背景质量的残差约 \(9.37\times10^{-17}\)。
- 协议、原生产代码和外部背景输入哈希全部与原记录一致；两份 CSV 的行数、排序、有限性及首末状态均与 JSON 对应。现存摘要和 CSV 的当前哈希另存于补充结果，检查前后相同；这些哈希是本次归档，不宣称它们在生产时已有外部认证。

球塌缩参照只描述平滑背景、球对称、无壳层交叉的尘埃动力学。PM 的实际包围质量、固定核心标签半径、轴比与径向散布仍须单独核验。后续即使接入特征温度和瞬时冷却时间，也不等于已经实现气体流体动力学、热化、成星或反馈。
