# 三维线性格点：微观迭代到宏观波动与协方差的验证协议

冻结日期：2026-09-24。此文件先于本目录的验证脚本运行写入；属于本地预先记录的计算协议，不是外部注册或盲测。

## 问题与范围

验证从给定三维线性格点递推到 Fourier 模式、长波色散、完整协方差和初谱退化的数学连接。只运行小型确定性计算；不加载 CMB 观测，不拟合天空，不检验宇宙学参数。下述迭代没有主 RSM 的自主时钟、质量项或非线性项，不能把这里的系数直接识别为主 RSM 的质量响应。

来源锚点为公开 CMB 仓库提交 `f42db51748003fc83be064dade9bb52de5eb8319` 的 `code/lattice_transfer.py`、`paper/main.tex` 和 `reports/theory_derivation.md`。本脚本独立实现算子、递推和矩阵检查，不导入相邻 CMB 项目的代码。以该提交固定源码哈希仅用于核对来源，不参与计算。

## 固定模型、索引与参数

在周期立方格点，定义

\[
(Lq)_{\boldsymbol x}=\frac16\sum_{i=1}^3(q_{\boldsymbol x+\boldsymbol e_i}+q_{\boldsymbol x-\boldsymbol e_i}-2q_{\boldsymbol x}),\quad
q_n=(2I+c_n^2L)q_{n-1}-q_{n-2},\quad q_{-1}=q_0.
\]

主检查执行 `N = 45` 次更新，系数索引为 `n = 1,...,45`，`c0 = 10`，`p = 0,2`。平方对数分支固定 `A2 = 0.45`；常数分支采用

\[
A_0=\left[\frac{\sqrt{0.45}}{45}\sum_{n=1}^{45}\frac1{\ln(n+10)}\right]^2
\]

匹配 `sum(sqrt(c_n^2))`。该匹配只固定长波累计相位代理量，不匹配每个模式的精确相位。所有量无量纲，格距和迭代间隔均为格点单位；`sqrt(c_n^2)/sqrt(6)` 才是长波每步传播代理量。初始条件是零后向差分，不是连续 ODE 零初速度的二阶起步。没有阻尼、裁剪、随机归一化或参数搜索。

## 独立检查与预定阈值

1. **坐标递推与 FFT 终态：** `12^3` 格点，固定 `default_rng(2026092404)` 标准正态初态，两种历史；相对 L2 差异小于 `1e-11`。验证归一化六邻居 Fourier 本征值 `lambda = 1 - (cos(kx)+cos(ky)+cos(kz))/3`；从坐标算子作用于选定 Fourier 模式核对，最大绝对残差小于 `1e-13`。
2. **常系数闭式：** 在 `lambda` 的 4097 个等距点 `[0,2]`，比较递推与 `cos((N+1/2)*omega)/cos(omega/2)`，`cos(omega)=1-A0*lambda/2`；最大绝对差小于 `2e-11`。端点 `lambda=0` 单独采用连续极限 `T=1`。
3. **二维模态辛性：** 两种历史、`lambda=0,0.2,1,2`，逐步和45步乘积分别检查 `M.T J M-J`，阈值为 `1e-14`、`1e-10`；45步行列式误差小于 `1e-10`。冻结耦合的全部选定模式满足 `c_n^2 lambda < 4` 只是局部振荡条件，不作为任意时变乘积稳定性的证明。
4. **长波系数与四阶各向异性：** 使用轴向、面对角线、体对角线三个单位方向。固定 `r=0.01` 检验 `lambda/r^2 -> 1/6`（相对偏差 `<1e-5`），以及 `(lambda-r^2/6)/r^4 -> -sum(d_i^4)/72`（绝对偏差 `<1e-7`）。在 `r=0.1,0.05` 比较主阶与四阶修正后的相对误差，估计阶分别落于 `[1.95,2.05]`、`[3.95,4.05]`。浮点求值用等价的 `lambda=(2/3)sum(sin(k_i/2)^2)` 减少小波数相消；另核对其与余弦表达式差异 `<1e-14`。
5. **完整协方差传播：** 独立 `4^3` 格点，不取径向平均。以固定随机种子产生 `K0=B B.T/64+0.2 I`，对其确定性平方根的全部列直接作坐标演化，再与 `F K0 F.T` 比较，相对 Frobenius 误差 `<1e-10`。这是线性代数验证，不依赖有限 Monte Carlo 样本协方差。
6. **初谱吸收退化：** 同一 `4^3` 模态空间，预先规定保留两个历史都满足 `|T|>0.1` 的模式；目标功率固定为 `0.1+1/(1+lambda)`，每个历史的输入功率取目标除以该历史 `T^2`。以坐标演化矩阵传播完整初始协方差，与保留子空间的目标协方差比较，相对误差 `<1e-10`；两终态协方差相对差异 `<1e-10`。记录被排除模式数、最小保留 `|T|`、最大输入功率及零/近零限制，不将自由初谱当作物理解释。
7. **有限求和诊断：** `p=0,1,2,3`，`N=45,100,1000,10000,100000,1000000`，`A=0.45,c0=10`，报告 `s_N/[sqrt(A/6) N/(ln N)^(p/2)]`。这里为单独渐近诊断，不沿用不同指数间的有限45步相位匹配。只要求有限、正值，且 `p=0` 比值距1小于 `2e-14`；不将有限计算作为渐近等价的证明或有限声学视界的证据。
8. **平均场：** 在坐标递推中逐步检查平均场保持其初始值，最大绝对偏差 `<1e-13`；这是本线性周期算子的求和性质，不是已识别的物质质量守恒。

脚本逐项记录全部通过或失败，不按运行结果调参或静默改阈值；失败应原样保存在报告并返回非零退出码。不存在观测拟合和显著性检验，也无模型偏好的结论。
