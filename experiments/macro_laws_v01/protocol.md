# 宏观收支规律的有限核验协议 v0.1

本协议在本目录的核验脚本第一次运行之前写定。它是仓库内的执行约定，未经外部注册，不称为公开预注册。

## 目标和范围

核验第4章从共同Hamilton得到的有限格距能量收支、主阶连续场能量与动量平衡，以及一个额外假设各向同性后的三维无质量波动压力关系。所有检查为小型符号计算或确定性数值代入；不积分宇宙演化、不拟合观测、不模拟真实物质或CMB。

核心Hamilton为

\[
H=\frac{P_R^2}{2I}+\sum_\ell\left[
\frac{p_\ell^2}{2a}+\frac{v^2(q_{\ell+1}-q_\ell)^2}{2a}
+a\left(\frac{M^2(R)q_\ell^2}{2}+\frac{gq_\ell^4}{4}\right)\right].
\]

所有格点使用周期边界，\(u_\ell=p_\ell/a\)。对称分配键能得到密度
\[
e_\ell=\frac{u_\ell^2}{2}+\frac{M^2q_\ell^2}{2}+\frac{gq_\ell^4}{4}
+\frac{v^2[(q_{\ell+1}-q_\ell)^2+(q_\ell-q_{\ell-1})^2]}{4a^2}.
\]
右向通量为\(J_{\ell+1/2}=-v^2(u_{\ell+1}+u_\ell)(q_{\ell+1}-q_\ell)/(2a)\)，源为\(s_\ell=[M^2]'\dot Rq_\ell^2/2\)。

## 检查与预定门限

1. **符号检查。** SymPy化简下列残差，要求严格等于0：有限格距单点局部能量方程；5点周期链上包含3点的区域边界通量方程；连续场\(e,J\)能量方程；连续场\(\mathcal P=-\phi_\tau\phi_x,\Pi\)动量方程；场和时钟的积分总能量关系。另检查候选推广\(G(R)|\nabla\phi|^2/2\)产生的时钟源为\(-G'\int|\nabla\phi|^2/2-[M^2]'\int\phi^2/2\)，及该推广的连续能量、动量恒等式。候选推广不冒充已经运行的CMB反馈模型。
2. **非均匀格点数值检查。** 固定NumPy PCG64种子20260925；\(N\in\{7,16,31\}\)、\(a\in\{0.03125,0.2,0.7\}\)，每组4个独立非均匀随机状态，共36例。\(q=0.4\,\mathcal N(0,1)\)、\(u=0.3\,\mathcal N(0,1)\)，\(p=au\)。固定\(I=7.5,v=0.9,g=0.2,R=1.4,\dot R=0.13,R_*=e^{-2},R_i=1,m_0^2=1,b=2\)。使用纯逆对数响应\(M^2=1+2[\ln^{-2}(R/R_*)-1/4]\)。
3. **独立RHS。** 数值Hamilton函数直接以\((q,p,R,P_R)\)求值，其梯度由步长\(10^{-25}\)的复步长法取得，再形成正则RHS；不调用待检验的局部通量恒等式产生RHS。此函数在所测试分支解析，复步长仅用于导数核验。将该RHS代入密度链式导数，检查局部收支、全场与时钟收支、三个区域的边界通量收支以及\(a\sum e_\ell=H_{\rm field}\)归一化。每例区域为起点0长度1、起点\(N-2\)长度\(\lfloor N/2\rfloor\)、起点1长度\(N\)，包含跨周期边界区域。
4. **数值门限。** 密度归一化相对残差门限\(5\times10^{-13}\)；局部、区域及总能量平衡的尺度化残差门限\(5\times10^{-12}\)。每个残差的尺度为对应等式各项绝对值的最大值与1取大值。绝对残差同时保存，不用趋近零的收支量作分母。复步长RHS还与独立逐键装配的解析Hamilton梯度比较，尺度化差异门限\(5\times10^{-12}\)。
5. **三维波动压力。** 使用6个等权方向\(\pm\hat x,\pm\hat y,\pm\hat z\)，独立均匀相位网格\(n_\theta\in\{16,32,64\}\)，幅度\(A\in\{0.4,1.2\}\)、波数模\(k\in\{0.3,2.1\}\)、速度\(v\in\{0.7,1.7\}\)，共24例。对单个线性无质量平面波逐点计算\(e\)、\(\Pi_{ij}\)，再对方向和相位取平均，检查\(\langle\Pi_{ij}\rangle=\langle e\rangle\delta_{ij}/3\)、能量\(A^2v^2k^2/2\)、平均动量为零。尺度化门限均为\(5\times10^{-13}\)。这里各向同性由人工方向设计给定，独立相位平均是数学集合，不是混沌自动热化或宇宙学模拟。附一个仅沿正x方向的对照，应得到\(\Pi_{xx}=\rho,\Pi_{yy}=\Pi_{zz}=0\)，以展示各向同性假设不可省略。

## 执行和记录

在仓库根目录执行：

```text
python experiments/macro_laws_v01/code/verify_conservation.py
```

只依赖Python、NumPy和SymPy；输入均在脚本内，不读取相邻论文目录或网络资料。脚本保存协议与源码SHA256、软件版本、全部分例残差、所有失败及中文报告。任一预设检查失败时仍写出结果，并以非零退出状态结束；不删除失败例，不在查看结果后改变门限。

这些恒等式针对连续时间的Hamilton格点方程及其主阶连续描述；它们不声称固定步长KDK逐步精确保存原Hamilton，不建立有限格距连续平移动量定理，也不给全局时钟赋予局域相对论传播。三维波动关系需要额外维度推广及各向同性假设；模型能量、时间、长度与物理单位的标定不在本轮范围内。
