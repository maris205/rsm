## 推导、实现与解释的对应

| 内容 | 来源与条件 | 本次检查 |
| --- | --- | --- |
| 局部能流和区域能量收支 | 已有自主场—时钟Hamilton量；对连续时间有限格点精确成立 | 符号恒等式、独立Hamilton梯度、非均匀周期状态与跨边界区域 |
| 连续场动量守恒 | 平滑场方程、空间均匀内部时钟、周期边界 | 符号微分；不声称一般非线性有限格点具有同一守恒动量 |
| 三维有效压力 | 线性无质量、相位平均、各向同性 | 人工六轴方向集合得到应力ρ/3；单方向波作反例对照 |
| 梯度耦合G(R) | 本次提出的自主扩展 | 仅符号核对场方程、梯度反作用及总能量；未作CMB反馈拟合 |
| 六邻域色散与传递 | CMB项目三维线性递推、q[-1]=q[0]、45步 | 坐标/FFT、常系数闭式、模态辛矩阵、长波误差阶 |

| N/ln N传播尺度 | 固定p=2、正系数、慢变求和的解析主项 | 有限求和诊断；不以有限计算证明渐近等价或有限视界 |

压力集合的各向同性是人为输入；未演化得到热平衡。CMB振荡峰是一般波动传递可产生的性质，常系数同样有峰，当前检查不支持指数2的独特性。
