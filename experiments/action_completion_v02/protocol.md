# 最小作用量候选：背景演化与条件预测核验

2026-09-22。用户授权在最小框架基础上继续补充驱动源、能量收支和观测响应。本实验是理论候选的内部验证，没有新增观测拟合，也不是完整宇宙学参数估计。

## 候选与判据

选取具有正则动能$F_\chi^2(\partial\chi)^2/2$、指数势$V_s e^{-2\chi}$的无量纲标量场。其电磁动能系数设为$B(\chi)=[1+\beta(\chi^{-2}-\chi_0^{-2})]^{-1}$。指数势与规范动能耦合属于既有方法；平方倒数响应是新框架保留的物理假设，不声称由黎曼零点或场方程唯一推出。

核验以下条件命题：

1. 无电磁平均源、单一常$w$流体的标度支上，$\chi=\ln(t/t_*)$与场方程和Friedmann方程相容，满足$V_s t_*^2=F_\chi^2(3h-1)/2$、$H=h/t$。
2. 加入常数真空能后，自主演化的场一般不继续保持精确对数时间。计算偏离及其对过去—当前α传递的影响，不逐步重置场值以强迫吻合。
3. 驱动场能量变化满足对应的连续性关系；数值积分容差与起始截断不能制造可见的物理偏离。
4. 示意α响应保持正值；给出的耦合—漂移—能量关系满足代数一致性。它不等同于第五力、等效原理或量子修正约束已被满足。

## 背景和初始条件

采用平直、物质加真空能加标量的理想背景，固定$H_{\rm ref}=67.4$ km/s/Mpc、今日物质参数0.315。示意取$\epsilon=(F_\chi/M_{\rm Pl})^2=10^{-6},10^{-4},10^{-2}$；这些是计算案例，不是由数据确定的允许区间。通过调整常数真空能参数使今日$H/H_{\rm ref}=1$，这项归一化不是预测了$H_0$。

在$a_i=10^{-3}$的物质标度近似上初始化，另用$a_i=10^{-4}$检验起始截断。该理想背景从一开始就不含辐射；早期初始化只是理想模型的计算延拓，不能称为完整真实早期宇宙。主要展示区间为$0\le z\le4.2$。

设$\tau=H_{\rm ref}t$、$N=\ln a$、$u=\chi-\chi_i$、$w_\chi^{\rm vel}=d\chi/d\tau$（代码须与物态参数$w_\chi=p_\chi/\rho_\chi$区分），$W=V/(F_\chi^2 H_{\rm ref}^2)$。用Friedmann约束给膨胀率，再独立积分场的二阶方程和年龄。势使用$W_i e^{-2u}$避免大指数相消。

主参考$t_*$沿用固定常规普朗克时间数值，仅用于设定这个候选的势尺度／初值；未从理论推出其等于物理基本时间。$D_0=2.5\times10^{-19}\,\mathrm{yr}^{-1}$仅作非零响应归一化示例，不是新增测量。

## 输出与边界

- 对照无真空能的解析物质标度支；收紧积分容差、改变起算点，并检查有限区间初值扰动。
- 保存$\chi,H,t,\Omega_\chi,w_\chi$及动力学α传递；与相同背景时间上的精确对数响应比较，另区分原固定ΛCDM背景的差异。
- 数值检验保留标量对Friedmann方程的反作用；忽略电磁／物质对标量的平均源。这是受控截断的候选分支，是否适用于真实物质须另算源强，不能仅凭标量能量小就认定。
- 不执行观测拟合，不添加“更优模型”的统计结论，不把场反演或正向恢复当成新的观测支持。
