# 实施记录与保留的限制

2026-09-22。本说明补充[冻结设计](../protocol.md)，不修改其文件或SHA-256。

1. **傅里叶门限约定。** 输入脚本的相对幅度／功率L2使用`numpy.fft.rfft`独立非负频率，排除直流、包括Nyquist，未对正负频率重复计权。自相关采用去均值序列的循环自相关。连续驱动诊断在$R\in[1,3]$上固定4097个采样点。
2. **输入质量失败保留。** 792个IAAFT中4个未达到幅度谱误差不超过5%的门限，全部进入预设主计算。失败列表在[input_summary.json](../results/input_summary.json)。追加的质量敏感性检查仅保留八块均通过节点门限的共同替代序号，剩95列；它不替代99列的主结果，也不是按动力学输出剔除样本。
3. **实际驱动不完全匹配。** 样条与窗会使实际连续驱动及导数的逐条功率谱不同；精确节点谱族也存在这一点。它是检验能够隔离哪些因素的限制，未用来重抽样、挑选块或重新调整耦合。
4. **独立参考的精度升级。** 原设置`rtol=1e-10, atol=1e-12, max_step=.01`有两项未过：最大能量／功相对误差$1.0575\times10^{-8}>10^{-8}$，收紧精度后的主指标差$1.3477\times10^{-9}>10^{-9}$。原结果完整保存在`reference_initial_*`。最终参考统一改为`1e-12,1e-14,.005`，再以`1e-13,1e-15,.0025`抽检第一真实块；最终五类检查通过。这修正积分精度，不改变源输入、主指标或物理参数。
5. **绘图修正。** 首次图生成因Matplotlib要求`\overline{T}`而非`\overline T`停止；统计计算已经保存。修正图轴标注后重新生成比较产物，没有重跑或改动动力学。随后将图例明确写为“Exact node spectrum”，避免与未严格匹配的连续驱动谱混淆。
6. **独立性的范围。** 主积分与独立DOP853参考由同一模型系列的不同代理分别实现；来源及方法复核另由代理只读完成。它们不是跨模型验证或外部盲同行评审，精确节点谱族也只是与IAAFT配对的敏感性检查。

旧v0.3额外精度门限失败和本轮初始参考精度失败都保留。当前完成状态不表示整个项目历史上所有检查通过。
