# 空间隔离候选的独立数值复核

2026-09-25。对应[实施说明](../protocol.md)。这份报告复核指定条件模型的系数换算、完整四维 K/W 的局部横向曲率和选定带电阈值响应。**它没有完成五维嵌入，也没有证明完整量子保护或真实宇宙中的稳定性。**

## 独立实现范围

[独立代码](../code/independent_check.py) 没有读取、导入或执行主实现。推导批次只使用父实验参数、1025 个旧 χ 坐标和实施说明；之后的比较批次读取主输出 CSV。两批代码路径的独立性属于同一 AI 系统内的内部复核，不能称作外部同行评议或独立研究团队。

原始 RSS 结果的纯半径系数和规范物质系数分别换算，并核对两者给出相同的

\[
A=\frac{\zeta(3)}{48\pi^4}\frac{m_{\rm KK}^2}{P}.
\]

采用 \(L_0=2\pi/m_{\rm KK}\)、\(M_{5,R}^3=2P/L_0\)。\(h_Q=1+A/t^3\) 的符号不能与半径修正任意独立选择。向移位型时钟 \(h_Z=1+\kappa A/t^3\) 的延拓仍是额外假设；κ=0、−1 是控制分支。[RSS 原始论文，式 (2.7)–(2.8)](https://arxiv.org/html/hep-th/0305184)；详细来源约定见[文献审计](../../../reports/protection_5d_20260925.md)。

## 完整 Kähler 逆矩阵检验

使用两个复场 T、Z，直接计算

\[
V=e^{K/P}\left(K^{i\bar j}D_iW\overline{D_jW}-\frac{3|W|^2}{P}\right),
\quad K=-3P\ln\Omega.
\]

代码保留 T 的辅助场，并在求横向二阶导数之前反演完整 2×2 Kähler 度规。没有把已稳定的 T 多重态预先删除。每个质量点只在 clock-off 真空调一次 η，同时求驻点 t；有限时钟计算保持这同一个 η，仅求 y=0 切片的径向驻点。

物理归一化与主约定相同：本轮 mG 是 clock-off 真空的物理 gravitino 质量，而不是未经 Kähler 因子修正的 Wc/P。固定

\[
W_c=P g_*^{3/2}m_G,\qquad
F_{\rm hol}^2=g_*F_\chi^2/h_{Z*},\qquad
U_{\rm hol}=g_*^2h_{Z*}U.
\]

对 y 的二阶导数除以实际动能系数 \(F_{\rm hol}^2h_Z/g\)。在 clock-off 且 q=g″=0 时，直接矩阵结果恢复

\[
m_y^2=2m_G^2(g/p)^2
\left[2(h'_Z/h_Z)^2-h''_Z/h_Z\right],\qquad p=g'.
\]

因此首阶负项确为 \(-24\kappa A m_G^2\)。有限 ρ 时，代码另用含 q 的完整解析质量式与矩阵数值微分逐点比较，没有把 q 设成零后再声称做了完整真空检验。

对有限时钟，简单首阶 \(4(U+\rho_\Lambda)/(3P)-24\kappa A m_G^2\) 在最小 mG 下会遗漏带 \(1/\epsilon\) 增强的交叉项。独立批次同时复核了实施说明补充的有限 ρ、有限时钟基线。定义

\[
r=\frac{\rho_\Lambda}{3Pm_G^2},\quad
w_m=\frac{F_\chi\sqrt U}{\sqrt2},\quad
\mathcal S=\left|e^{i\theta}-\frac{w_m}{m_GP}\right|^2,
\]

使用

\[
m_{y,\mathrm{ref}}^2=
\frac{4(1+r)U}{3P}
-\frac{2r m_Gw_m\cos\theta}{F_\chi^2}
+2r m_G^2(2+r)\mathcal S
-24\kappa A m_G^2.
\]

这仍是保留指定阶的近似式；完整矩阵计算用于估计它在选定点上的误差。

## 完成的计算

- 独立重算 3 个 mG、3 个相位、1025 个 χ 的单位 c 响应，共 9225 个点，并给出条件预算。
- 18 个 clock-off 点：mG=10⁻²⁴、10⁻¹⁶、1 eV，mKK=1、100 TeV，κ=−1、0、1。
- 54 个有限时钟点：同三个 mG，mKK=1 TeV，三种 κ，θ=0、π/2、π，χ 区间两端。每一点先在固定 η 下求径向驻点。
- 上述共 72 点分别用 140 位和 220 位精度计算。相位 0、π/2、π 的余弦和正弦使用精确整数，避免把浮点近似零误作物理源项。

直接推导与精度批次 **153/153** 检查通过。140→220 位的最大质量差，以正背景与圈修正绝对值之和归一化，为 **1.06×10⁻⁸³**。clock-off 简化式的最大归一化偏差为 **7.08×10⁻¹⁹**。有限时钟的简单首阶式偏差达到 **3.60×10⁻⁹**；补上上述有限 ρ 交叉项后为 **4.67×10⁻¹⁷**。这说明为何最低质量点需要保留该项，不能把不够精确的首阶式当作精确答案。

详细输出见 [140 位批次](../results/independent_kahler_140.csv)、[220 位批次](../results/independent_kahler_220.csv) 和[独立汇总](../results/independent_summary.json)。检查数量表示软件及代数覆盖，不是多份独立物理证据。

主输出比较覆盖 **19,215 个网格点、144 个代表点**，以及四个 KK 质量上的条件边界。对每个不同质量/相位先独立计算全部 1025 个 χ 的响应，再比较 A、c、β、选定两环力、改变有限边界后的力、β² 三环诊断、曲率端点、质量层次和布尔分类。[比较汇总](../results/independent_comparison.json) 为 **22/22** 检查通过，最大归一化差异 **1.63×10⁻¹⁴**，分类差异为零。曲率比较按正背景与圈项绝对值之和归一化，避免在相消点使用接近零的分母；其他非零量按相应预测值归一化。统一比较阈值为 10⁻¹¹。

## 条件例子与解释边界

取 mKK=1 TeV、κ=1，clock-off 的独立结果为：

| mG | 局部横向曲率 \(m_y^2\) / eV² | 固定背景负曲率时间 \(\hbar/\sqrt{|m_y^2|}\) |
|---|---:|---:|
| 10⁻²⁴ eV | +5.662657616966348×10⁻⁶⁶ | 正曲率，不定义此时间 |
| 10⁻¹⁶ eV | −4.743672752480924×10⁻⁶⁶ | 3.022097048799873×10¹⁷ s |
| 1 eV | −1.040633036944727×10⁻³³ | 20.40407741655377 s |

20 秒是固定局部背景的线性增长时间尺度，不是已经模拟出来的宇宙演化寿命。接近 Hubble 时间的点尤其需要加入实际背景演化；当前实验没有这条新宇宙轨迹。

对同一 1 eV 点，独立的 ν₀=0、选定带电 c 响应给出

\[
|c|_{10\%}=1.231998201276898\times10^{-32},\qquad
(m_Gm_{\rm KK})_{10\%}=4.865990201326439\times10^{12}\;\mathrm{eV}^2.
\]

这是指定有限边界下的选定两环预算，不是实验排除限。它允许该 1 eV、1 TeV 点的带电反馈很小，但这并不能消除 κ=1 条件时钟分支的横向负曲率。来源 c≈12A 与时钟曲率修正之间有直接关系 \(\Delta m_y^2\simeq-2\kappa c m_G^2\)。

有限时钟 θ=π/2 的 y=0 一般有非零斜率；表中的 Vyy/Gyy 是该切片的局部曲率，不能称作已求出的二维谷底质量。即使切片曲率为正，也还需完整滚动背景、场空间动力学、额外算符和完整匹配的检验。κ=−1 的反号控制不是 RSS 已预测的时钟保护机制。

## 保留的失败和修正

1. 首次精度批次 **44/45**。mG=1 eV、mKK=100 TeV、κ=0 的真空能极小，直接对真空方程使用绝对根求解容差，使 140→220 位的归一化质量差为 9.59×10⁻⁵⁴，未达 10⁻⁶⁵。把真空残差除以目标真空能、径向残差除以其自然尺度后，保持精度和比较阈值不变，批次通过。原始表、汇总和日志保存在 `independent_initial_*`。
2. 前两次主输出比较均为 **21/22**。比较器最初沿用了计划中的 mG² 缩放近似，但最终主实现对代表点和整个主网格都保留实际质量、相位的响应核修正。先修正代表点比较，再确认主网格也已经使用实际质量核，最终比较器对每个不同质量/相位重新计算全部 1025 个 χ 响应。遗漏这项时差异为 1.57×10⁻⁹，阈值保持 10⁻¹¹。两次比较及日志分别保存在 `independent_first_comparison.*`、`independent_second_comparison.*`。这是比较器与实际输出约定的错位，不是对物理模型的改动。

这些是实际发生的数值/比较约定修正；失败记录没有被删除，也没有通过放宽阈值取得通过。CSV 使用 LF 行尾。

## 复算

在仓库根目录运行：

```bash
python experiments/sequestering_test_v01/code/independent_check.py --derive --compare
```

`--derive` 不依赖主输出；`--compare` 读取主扫描、代表点与条件边界 CSV。独立代码、父输入、实施说明以及被比较的主输出均记录 SHA-256。本报告只支持上述条件部门的数值一致性；完整超引力圈图、五维稳定化与时钟边界作用量、真实标准模型、1/ln²t 指数来源及黎曼到相互作用的推导仍未完成。

最终归档批次环境为 Python 3.12.3、mpmath 1.3.0；源文件和主输出哈希核对一致。增长时间诊断列补入主 CSV 后，独立推导与全部比较已对最终文件重新运行。
