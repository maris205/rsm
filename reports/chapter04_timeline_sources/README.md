# 第四章时间线图的小型来源快照

本目录只选取已经保存的场切片和逐步诊断，为图4.3提供可独立绘制的输入。没有重新演化格点、优化初态或拟合观测。原始约61 MB的三维状态档案不复制到RSM；此处约300 KB的NPZ只支持图形复现，不能单独重新运行完整三维演化。

来源固定为[riemann_cmb提交f42db517](https://github.com/maris205/riemann_cmb/tree/f42db51748003fc83be064dade9bb52de5eb8319)。提取脚本逐一比较源工作区文件与该Git提交的blob字节，而非仅记录当时HEAD。`manifest.json`保存六个源文件的SHA256、字节数及固定链接，同时保存本目录五个输入/说明文件的哈希。

## 数据选择与单位

`timeline_snapshot.npz`保留以下内容：

| 字段 | 形状 | 来源与意义 |
|---|---|---|
| `slices_z48` | `(4,96,96)` | 原`snapshots[:, :, :, 48]`，对应实际演化状态0、45、70、95；原float64逐值保留 |
| `snapshot_steps` | `(4,)` | `[0,45,70,95]` |
| `steps` | `(96,)` | 全部模型迭代0至95 |
| `histories` | `(4,96,5)` | 四分支每步的完整三维场诊断，未由二维切片重新计算 |
| `branch_names` | `(4,)` | 主双阱分支、无局部力、仅晚期常系数、无晚期阻尼 |
| `c2_p2` | `(96,)` | 已保存的平方对数系数，0号位置NaN表示尚未更新 |
| `metadata_json` | 标量字符串 | 固定来源、切片选择、单位、颜色范围、历史列定义及解释边界 |

历史的五列依次是均值、方差、平均梯度粗糙度、梯度长度代理量及最大绝对场幅度。图下方使用第2列，即整个96³体积的总体方差；它不是所示二维切片的方差。场值及方差均保留原始无量纲单位，未按每幅图的幅度分别归一化。四张中央切片共用固定色标`[-3.2,3.2]`；提取检查确认该范围未截断所示切片。它不是全部三维体积的幅度上界。

`lattice_timeline_source.json`和`timeline_verification_source.json`为原JSON的逐字节副本。后者记录既有52/52检查通过，包括独立重演主非线性分支；其他分支检查了末态及共同前段，并未全部独立重演。本次提取没有重跑那份科学验证。提取脚本另外检查来源字节、选择形状、共同历史、三维方差及JSON之间的一致性。

## 状态序列怎样解释

初态由同一CMB逆问题拟合得到，不是独立预测的宇宙初始状态；`n=0`为有限模型初值，不是计算得到的大爆炸奇点。前45步为无阻尼线性平方对数系数演化，45步是样本内CMB约束锚点。70步是真实保存的中间状态，不是首尾图像插值。

四个后期分支保留同一`q44,q45`，从46步起延续，没有清零速度、剪裁场值或再次拟合。主分支加入局部力`0.05q-0.01q^3`与阻尼`eta=0.015`。常系数对照仅替换46至95步的空间耦合，取`c²=0.023629776358038895`，匹配相同后期`sum(sqrt(c_n²))`；前45步仍与其他分支相同。因此图例使用“仅晚期常系数”，不把它称为全历史常系数拟合。

方差既不是熵，也不是空间膨胀率；早期方差降低不能解释为已模拟宇宙暴涨。模型没有宇宙年龄标定、膨胀几何、Poisson引力或物质密度识别，晚期有符号场域不标为真实星系或暗物质。该图展示规定动力学中的演化与算子对照，不增加CMB声学峰匹配或宇宙学观测证据。

## 复现

在RSM根目录，直接用本目录的小快照验证并绘图，无需相邻CMB仓库：

```bash
python reports/chapter04_timeline_sources/extract_timeline_snapshot.py --verify-local
python manuscript_cn/figures/make_chapter04_timeline_figure.py
```

如要从固定源档案重新提取，显式提供源仓库目录：

```bash
python reports/chapter04_timeline_sources/extract_timeline_snapshot.py --source-root /path/to/riemann_cmb
```

提取依赖NumPy和Git；绘图依赖NumPy、Matplotlib及仓库已有的中文字体设置，不需要healpy。`manifest.json`为提取记录，不哈希自身；每次改变提取脚本或本说明后，应重新提取以刷新其哈希。
